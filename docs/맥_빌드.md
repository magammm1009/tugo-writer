# 맥에서 빌드하는 법

맥용 앱은 맥에서만 만들 수 있어요. 처음 한 번만 준비하면 다음부터는 명령 한 줄이에요.

## 처음 한 번

1. **파이썬 설치**: https://www.python.org/downloads/macos/ 에서 최신 3.12/3.13 설치본(Tk가 함께 들어 있음).
   맥에 기본으로 있는 python3는 Tk가 오래돼서 화면이 깨질 수 있어요.
2. **저장소 받기**(터미널):
   ```
   git clone https://github.com/magammm1009/tugo-writer.git
   cd tugo-writer
   ```
   이미 받았으면 `git pull`.

## 빌드

```
bash tools/build_mac.sh 2.3
```

- 결과: `dist/투고 양식 자동 작성기.app`, `dist/TugoWriter-2.3.dmg`
- 버전 숫자는 `app.py`의 `VERSION`과 같아야 해요.

## 먼저 직접 확인하기

1. `dist/투고 양식 자동 작성기.app`을 오른쪽 클릭 → 열기.
2. 확인할 것
   - [ ] 글자가 깨지지 않고(애플 SD 산돌고딕 Neo), 창 크기·사이드바가 정상
   - [ ] 「일괄 작성 · 저장」에 양식 71개가 자동으로 잡힘(앱 안에 넣은 묶음)
   - [ ] 예시 작품(불러오기 → `예시_작품.json`)으로 일괄 저장 → 결과 폴더가 Finder로 열림 → 한컴오피스 맥용으로 hwpx가 열림
   - [ ] 트랙패드·휠 스크롤이 너무 빠르거나 느리지 않음(조절: `app.py`의 `0.35`)
   - [ ] ④ 투고하기 「주소 복사」 → 붙여 넣기 됨, 「사이트 열기」 → 브라우저
   - [ ] 테마 바꾸기, 도움말 → 지금 업데이트 확인
3. 문제가 있으면 맥에서 Claude Code를 열고 이 저장소 폴더에서 고쳐 달라고 하면 돼요(이 문서와 화면 캡처를 함께).

## 올리기

1. GitHub Releases의 같은 버전(v2.3)에 `TugoWriter-2.3.dmg` 첨부.
2. manifest에 맥 주소 추가 후 push:
   ```
   python3 tools/publish_update.py app --version 2.3 --mac dist/TugoWriter-2.3.dmg
   git add update && git commit -m "맥 v2.3" && git push
   ```

## 참고: 서명·공증

- 지금은 서명하지 않은 앱이라 받는 사람이 「오른쪽 클릭 → 열기」를 한 번 해야 해요(README에 안내).
