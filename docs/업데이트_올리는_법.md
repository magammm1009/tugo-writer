# 업데이트 올리는 법

설치한 프로그램은 켤 때마다 `update/manifest.json`(이 저장소 main 브랜치)을 읽어 새 것이 있는지 확인해요.

- `data`: 양식·투고처 묶음 → 새 것이 있으면 **자동으로** 받아 반영
- `app`: 프로그램 → 새 버전이 있으면 **알림**만(작가님이 누르면 설치 파일을 받아 설치)

## A. 양식·투고처만 새로 올릴 때 (자주)

1. 묶음 폴더(`투고양식_묶음_202611/`)를 고친다.
   - 투고처 다시 모으기: `python tools/collect_submit.py <묶음>/양식목록.json <묶음>.zip <묶음>/투고처.json`
   - 새 양식 추가: `tools/collect_forms.py` → `download_forms.py` → 한컴오피스 변환(`convert_to_hwpx.ps1`) → `build_bundle.py`
2. 업데이트 파일 만들기(날짜는 오늘):
   ```
   python tools/publish_update.py data --bundle ../투고양식_묶음_202611 --version 2026-12-15 --notes "투고처 갱신"
   ```
3. 올리기:
   ```
   git add update && git commit -m "양식·투고처 2026-12-15" && git push
   ```
   몇 분 뒤부터 작가님들 프로그램이 켤 때 새 묶음을 받아요.

## B. 프로그램 새 버전을 올릴 때

1. `app.py`의 `VERSION`을 올린다(예: `2.4`).
2. 윈도우 설치 파일: `powershell -ExecutionPolicy Bypass -File tools\build_windows.ps1 -Version 2.4`
3. 맥(맥에서): `bash tools/build_mac.sh 2.4` — [맥_빌드.md](맥_빌드.md)
4. GitHub → Releases → **Draft a new release** → 태그 `v2.4` → 설치 파일(`dist/TugoWriter-Setup-2.4.exe`, `dist/TugoWriter-2.4.dmg`)을 첨부 → Publish.
   파일 이름을 바꾸지 말 것(manifest 주소가 이 이름을 씀).
5. manifest 고치기(윈도우·맥 중 만든 것만 적어도 됨, 나중에 다른 쪽을 같은 버전으로 추가 가능):
   ```
   python tools/publish_update.py app --version 2.4 --windows dist/TugoWriter-Setup-2.4.exe --notes "바뀐 점 한 줄"
   git add update app.py && git commit -m "v2.4" && git push
   ```
   **릴리스에 파일을 올린 뒤에** manifest를 push해야 해요(순서가 바뀌면 작가님 쪽에서 받기 실패).

## 확인

- 브라우저로 https://raw.githubusercontent.com/magammm1009/tugo-writer/main/update/manifest.json 이 새 내용으로 보이는지(반영까지 몇 분 걸릴 수 있음).
- 프로그램 「도움말 → 지금 업데이트 확인」.
