# 투고 양식 자동 작성기

작품 정보를 한 번 입력하면 웹소설 출판사 **투고 양식(HWPX)을 한꺼번에 채워 주는** 프로그램이에요.
BL · 로맨스 · 로맨스판타지 · 현대로맨스 · 19단편 장르의 출판사 양식과 투고처(이메일·구글 폼·홈페이지)가 들어 있어요.

## 내려받기

[**Releases**](https://github.com/magammm1009/tugo-writer/releases/latest)에서 내려받으세요.

| 운영체제 | 파일 | 설치 |
|---|---|---|
| 윈도우 10/11 | `TugoWriter-Setup-<버전>.exe` | 더블클릭 → 「다음」 → 「설치」. 관리자 권한이 필요 없어요. |
| macOS | `TugoWriter-<버전>.dmg` | 열어서 앱을 「응용 프로그램」으로 끌어 놓기. |

### 처음 실행할 때 경고가 뜨면
개인이 만든 프로그램이라 코드 서명 인증서가 없어서 뜨는 창이에요.
- **윈도우**: 「Windows의 PC 보호」 → **추가 정보** → **실행**
- **맥**: 「확인되지 않은 개발자」 → 앱을 **오른쪽 클릭 → 열기** → **열기**
  (안 되면 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 「그래도 열기」)

## 이렇게 써요

1. 왼쪽 순서대로 작가 정보 → 작품 → 소개·기획 → 등장인물 → 줄거리 → 분량·연재·출간 → 확인 사항을 채워요(입력하는 즉시 자동 저장).
2. 「일괄 작성 · 저장」에서 장르 탭을 고르고 **▶ 선택한 양식 일괄 저장**.
3. 아래 **④ 투고하기**에서 이메일 주소를 복사하거나 구글 폼·홈페이지를 바로 열어 투고해요.
4. 결과 보고서에서 빈칸·직접 확인할 칸을 보고, 한컴오피스로 열어 마무리해요.

## 자동 업데이트

- 켤 때 **새 양식·투고처**가 있으면 알아서 받아 반영해요(도움말에서 끌 수 있어요).
- **프로그램 새 버전**이 나오면 위쪽에 「⬆ 새 버전 받기」가 보여요. 누를 때만 받아 설치해요.
- 받은 파일은 확인값(SHA-256)이 맞을 때만 쓰고, 이 저장소(GitHub) 주소에서만 받아요.

## 알아 두세요

- 투고처는 출판사 사정에 따라 바뀔 수 있어요. 보내기 전에 「안내 글」을 한 번 확인하세요.
- 원고 본문은 넣지 않아요. 출판사 안내대로 원고를 붙이거나 첨부하세요.
- 작가님이 입력한 내용은 각자 컴퓨터에만 저장돼요(윈도우 `%APPDATA%\BL투고양식작성기`, 맥 `~/Library/Application Support/BL투고양식작성기`).
- 「BL 투고 양식 자동 작성기」(제작: 정체불명위스키)의 흐름을 바탕으로 새로 만든 프로그램이에요.
  양식은 각 출판사가 공개한 투고 양식이고, 투고처는 [투고하다](https://toogohada.com)와 출판사 안내를 참고했어요.
